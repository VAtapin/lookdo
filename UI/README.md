# LOOKDO — обязательные UI-референсы Tenant App

Файлы в этой папке — **утверждённые визуальные референсы клиентского Web App/PWA LOOKDO**.

## Жёсткое правило для Codex

При реализации **Части 2 — Tenant App** необходимо **строго держаться этих макетов** по:

- общей композиции экранов;
- расположению элементов;
- мобильной app-like структуре;
- размерам и иерархии блоков;
- нижней навигации;
- карточкам;
- модальным окнам / bottom sheets;
- логике camera/upload flow;
- сообщениям;
- отзывам;
- экрану профиля;
- служебным состояниям.

Нельзя самостоятельно заменять этот UI на типовой dashboard, Bootstrap/Filament-подобный публичный интерфейс, классический сайт-лендинг или придумывать новую структуру экранов.

Изображения являются **референсами дизайна, а не готовыми bitmap-экранами**: интерфейс должен быть реализован нормальными responsive Vue-компонентами.

### Что можно менять у tenant

Структура UI остаётся фиксированной. Tenant может настраивать только предусмотренный брендинг и контент, в частности:

- основной/акцентный цвет;
- дополнительный цвет;
- логотип;
- название;
- фотографии/видео;
- тексты;
- контакты;
- данные своего бизнеса.

Чёрно-золотая тема изображений — исходный эталон LOOKDO/первого tenant, но цвета должны работать через theme variables/tokens и заменяться настройками tenant.

### Адаптивность

Макеты ориентированы прежде всего на телефон. На планшете/desktop интерфейс должен аккуратно адаптироваться, **не превращаясь в другой продукт**. Mobile-first структура и UX сохраняются.

Если между общим предположением разработчика и макетом из `UI/` есть расхождение, для Tenant App **приоритет имеет утверждённый макет**, если это не противоречит безопасности, accessibility или явно зафиксированной бизнес-логике проекта.
