# LOOKDO

> **LOOK. DO.**  
> **СМОТРИ. ДЕЛАЙ.**

**LOOKDO** — мультитенантная SaaS-платформа для сервисного бизнеса и мастерских. Конечный клиент не заполняет длинные анкеты и не получает автоматическую «цену из калькулятора»: он показывает мастеру задачу фотографиями или коротким видео, оставляет обязательный номер телефона и получает ответ живого специалиста.

Основной домен платформы: **lookdo.app**

## Главная идея

Клиент показывает — мастер смотрит и делает.

Типовой путь:

**бизнес/работы → фото или видео задачи → обязательный телефон → заявка → уведомление мастеру → ответ → сообщения/push/звонок → договорённость**.

LOOKDO должен оставаться простым. Новая профессия не создаёт новый frontend и новые экраны. В базе хранится фиксированная таксономия направлений и вариантов заявок, а AI при регистрации бизнеса помогает определить подходящую пару **категория + вариация** по свободному описанию деятельности и словарю фраз.

## Клиентское приложение

Основная навигация всегда минимальна:

**Главная · Основное действие · Сообщения**

Примеры работ «До/После» находятся на Главной; отдельный постоянный раздел «Работы» не нужен. Дополнительные состояния — камера/медиа, заявка отправлена, разрешение push, отзывы и контакты.

## SaaS

Каждый бизнес — отдельный tenant со своим брендом, цветами, контентом, заявками, сообщениями, отзывами, интеграциями и собственным доменом. Клиент самостоятельно регистрирует домен и направляет DNS на сервер LOOKDO; система подключает домен и SSL.

Первый реальный tenant — мастерская Леонида по перетяжке рулей. Никакой отдельной логики для Леонида нет: это обычный tenant, которому через Super Admin можно назначить нужный тариф бесплатно.

## AI-классификация деятельности

При регистрации владелец пишет деятельность обычными словами, например:

- «перетягиваю автомобильные рули»;
- «устанавливаю входные двери»;
- «ремонтирую стиральные машины».

LOOKDO ищет совпадения и близкие формулировки в словаре и использует AI как классификатор. AI **не создаёт новые шаблоны**: он выбирает только из фиксированных категорий и вариаций. При низкой уверенности пользователю показываются 2–3 подходящих варианта.
