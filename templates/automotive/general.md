# LOOKDO Template — Автомобили и автосервис / универсальный

**Код:** `automotive.general`  
**Категория:** Автомобили и автосервис  
**Тип:** универсальный / fallback  
**Исходный язык:** RU  
**Видео:** разрешено  
**Телефон клиента:** обязательно  
**Фото:** 1–4, рекомендуется 3–4

Этот шаблон используется, если LOOKDO определил автомобильную деятельность, но не найден более точный адресный шаблон.

## 1. Основное действие

**Кнопка:** `📷 Показать автомобиль`

**Заголовок:** `Покажите, что нужно сделать`

**Вводный текст:**

> Сделайте несколько фотографий автомобиля, детали или места, с которым нужно работать. Покажите сначала общий вид, затем нужную часть ближе и важные детали.

Не использовать формулировки «точная оценка по фотографии» или «диагностика по фото». Мастер получает материалы для первого ответа и сам принимает решение после просмотра.

## 2. Фото

### Фото 1 — Общий вид

**Название:** `Общий вид`

**Инструкция:**

> Сфотографируйте автомобиль или нужную часть целиком.

**Подсказка:**

> По фотографии должно быть понятно, где находится место, с которым нужно работать.

**Обязательность:** рекомендуется, но технически достаточно одного фото.

**Hint image key:** `automotive/general/overall`

### Фото 2 — Нужная часть

**Название:** `Покажите нужное место ближе`

**Инструкция:**

> Сфотографируйте часть автомобиля, которую нужно отремонтировать, заменить, восстановить или изменить.

**Обязательность:** необязательно.

**Hint image key:** `automotive/general/area`

### Фото 3 — Деталь крупным планом

**Название:** `Покажите детали`

**Инструкция:**

> Снимите крупным планом повреждение, износ, соединение, шов, деталь или другое важное место.

**Обязательность:** необязательно.

**Hint image key:** `automotive/general/detail`

### Фото 4 — Другой ракурс

**Название:** `Ещё один ракурс`

**Инструкция:**

> Если это поможет лучше понять задачу, добавьте фотографию с другой стороны.

**Обязательность:** необязательно.

**Hint image key:** `automotive/general/another-angle`

## 3. Работа с фотографиями

Для каждого слота доступны:

- `📷 Сделать фото`
- `🖼 Выбрать из галереи`
- `Использовать фото`
- `Переснять`
- `Удалить`

После первого фото показывать `Добавить ещё фото`. Не заставлять пользователя проходить все четыре слота.

## 4. Видео

**Действие:** `🎥 Добавить короткое видео`

**Подсказка:**

> Если проблему лучше показать в движении или она сопровождается звуком, снимите короткое видео.

Видео особенно полезно, если что-то шумит, вибрирует, заедает, течёт, двигается неправильно или проблема проявляется только при определённом действии.

**Hint image key:** `automotive/general/video`

## 5. Данные автомобиля

Использовать универсальные `request_fields`, не отдельные колонки таблицы `requests`.

### Марка
- key: `vehicle_brand`
- type: `text`
- placeholder: `Например: BMW`
- required: `false`

### Модель
- key: `vehicle_model`
- type: `text`
- placeholder: `Например: X5`
- required: `false`

### Год
- key: `vehicle_year`
- type: `text`
- required: `false`
- по умолчанию может быть скрыт под «Дополнительно».

## 6. Описание задачи

**Заголовок:** `Что нужно сделать?`

**Тип:** textarea

**Placeholder:**

> Коротко напишите, что нужно отремонтировать, заменить, восстановить или изменить.

**Required:** `false`

Фотографии остаются главным способом обращения.

## 7. Телефон

**Заголовок:** `Ваш номер телефона`

**Подсказка:**

> Оставьте номер, чтобы мастер мог связаться с вами после просмотра заявки.

Телефон всегда обязателен. Формат/placeholder зависит от страны tenant.

E-mail конечного клиента в стандартной заявке не используется.

## 8. Предпочтительный способ ответа

Если tenant подключил соответствующие каналы, можно показать необязательный выбор:

- В приложении
- По телефону
- VK
- Telegram — только если реально подключён

Телефон всё равно сохраняется как обязательный fallback.

## 9. Отправка

**Кнопка:** `Отправить мастеру`

Во время загрузки: `Отправляем фотографии…`

После успеха:

> **Готово!**  
> Заявка отправлена мастеру. Он посмотрит фотографии и свяжется с вами.

Показать номер заявки, например: `Заявка №1234`.

## 10. Push после отправки

Сначала собственный pre-prompt:

**Заголовок:** `Не пропустите ответ`

**Текст:**

> Разрешите уведомления, и мы сообщим, когда мастер ответит.

Кнопки:

- `🔔 Разрешить уведомления`
- `Не сейчас`

Только после первой кнопки вызывать системный browser/PWA permission prompt.

## 11. Контакт после отправки

На success-state допускаются:

- `💬 Открыть сообщения`
- `📞 Позвонить`
- `VK Написать` — если подключён

Конечного клиента не заставлять создавать аккаунт только ради просмотра собственной заявки/переписки. Использовать безопасную session/token/link механику.

## 12. Иллюстрации-подсказки

Шаблон поддерживает собственные hint illustrations:

```text
automotive/general/overall
automotive/general/area
automotive/general/detail
automotive/general/another-angle
automotive/general/video
```

Если иллюстрации отсутствуют, шаблон обязан корректно работать только с текстовыми подсказками.

## 13. Что tenant может изменить

Tenant может менять:

- CTA;
- вводный текст;
- label/placeholder комментария;
- какие дополнительные универсальные поля показывать;
- разрешение видео;
- максимум фото;
- свои пояснения;
- локализованные тексты.

Tenant не меняет:

- общий flow;
- обязательность телефона;
- camera/upload UI;
- Messages;
- success flow;
- push flow;
- структуру БД.

## 15. Fallback

Порядок:

1. точный адресный шаблон;
2. близкий специализированный шаблон при достаточной уверенности;
3. `automotive.general`;
4. если даже категория неясна — поддержка.

Текст:

> **Не нашли подходящий шаблон?**  
> Напишите нам, чем вы занимаетесь. Мы посмотрим и добавим подходящий вариант.

Кнопка: `Написать в поддержку`

## 16. Универсальные данные заявки

```text
requests
- id
- tenant_id
- template_id
- customer_phone
- comment
- status
- created_at
```

```text
request_fields
- request_id
- field_key
- value
```

```text
media
- request_id
- slot_key
- type
- sort_order
- file
```

Новый специализированный автомобильный шаблон наследует этот flow и меняет только свою конфигурацию: тексты, media slots, hint illustrations, поля и AI-фразы.
