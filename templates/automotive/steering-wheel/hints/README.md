# Иллюстрации-подсказки — Перетяжка руля

Эта папка предназначена для специализированных визуальных подсказок шаблона `automotive.steering-wheel-upholstery`.

Нужные файлы:

- `overall.svg` — руль целиком;
- `top.svg` — подсвечена верхняя часть обода;
- `left.svg` — подсвечена левая часть;
- `right.svg` — подсвечена правая часть;
- `bottom.svg` — подсвечена нижняя часть;
- `damage.svg` — пример крупного плана повреждения/износа/шва.

## Требования

- единый визуальный стиль;
- простая схема, а не случайная фотография;
- хорошо читается на маленьком экране;
- лёгкий SVG;
- не привязывать к конкретной марке автомобиля;
- схема должна помогать понять именно ракурс/зону съёмки;
- использовать внутри уже утверждённых карточек/экранов из `/UI`, а не создавать для неё новый UI.

Codex не должен генерировать новые экраны из-за этих изображений. Hint illustrations — контент внутри существующего UI.
