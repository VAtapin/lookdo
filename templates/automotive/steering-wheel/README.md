# LOOKDO — шаблон «Перетяжка руля»

**Код:** `automotive.steering-wheel-upholstery`  
**Категория:** Автомобили и автосервис  
**Родительский шаблон:** `automotive.general`  
**Тип:** специализированный адресный шаблон  
**Приоритет:** высокий — первый реальный клиент LOOKDO

## КРИТИЧЕСКОЕ ПРАВИЛО ДЛЯ CODEX

Этот шаблон должен быть реализован **строго по утверждённым макетам из папки `/UI`**.

Нельзя:

- менять структуру экранов;
- превращать flow в обычную веб-форму;
- переносить элементы в другой порядок без необходимости;
- заменять app-like UX на dashboard/landing UI;
- придумывать новый camera/upload flow;
- менять расположение основной нижней навигации;
- делать отдельные экраны там, где по UI предусмотрено состояние/карточка/modal/bottom sheet;
- упрощать или «улучшать» утверждённый визуальный принцип по своему усмотрению.

При конфликте между предположением разработчика и утверждёнными изображениями в `/UI` **приоритет имеют изображения `/UI`**, если это не противоречит безопасности, accessibility или явно зафиксированной бизнес-логике.

Макеты `/UI` — это визуальный эталон. Реализация должна быть нормальными responsive Vue-компонентами, а не картинками.

---

# 1. Назначение шаблона

Шаблон используется для мастерских и мастеров, которые занимаются:

- перетяжкой автомобильных рулей;
- обшивкой рулей кожей;
- восстановлением кожи руля;
- реставрацией руля;
- изменением материала/строчки;
- утолщением или изменением формы руля;
- комбинированной отделкой руля.

Главная цель: клиент должен быстро и правильно показать руль так, чтобы мастер получил достаточно информации для первого ответа без длинной анкеты.

---

# 2. Основное действие

**CTA:**

> 📷 Оценить мой руль

Эта кнопка должна оставаться постоянно заметной в app UI согласно макетам `/UI`.

**Заголовок формы:**

> Покажите ваш руль

**Вводный текст:**

> Сделайте несколько фотографий руля. Покажите его целиком и крупно основные части — так мастер сможет увидеть форму, состояние материала, швы и повреждения.

---

# 3. Подготовка к съёмке

Перед первым фото показать короткую визуальную подсказку:

> Поставьте колёса прямо и расположите руль ровно. Снимайте при хорошем освещении, без сильных бликов. Руль должен быть хорошо виден целиком.

Дополнительная строка:

> Если в салоне темно, включите свет или снимайте днём.

Эта подсказка должна быть компактной и вписываться в утверждённый UI, а не становиться отдельной длинной страницей.

**Ключ:** `overall`

**Название:**

**Инструкция:**

# 5. Референс желаемого результата

Отдельный media slot:

**Ключ:** `reference`

**Заголовок:**

> Есть пример того, как вы хотите?

**Подсказка:**

> Можно добавить фотографию другого руля, материала, строчки или варианта оформления, который вам нравится.

**CTA:**

> 🖼 Добавить пример

**media_role:** `reference`

Это не фото состояния текущего руля и должно храниться отдельно по роли.

# 6. Работа с фото

Для каждого фото доступны действия согласно `/UI`:

- Сделать фото;
- Выбрать из галереи;
- Использовать фото;
- Переснять;
- Удалить;
- Добавить ещё.

Не заставлять клиента проходить все слоты как жёсткий wizard. Подсказки направляют клиента, но flow остаётся лёгким.

---

# 7. Видео

Видео поддерживается, но для стандартной перетяжки руля **не является главным действием**.

Настройки:

- `video_allowed = true`
- `video_recommended = false`

Видео можно спрятать в дополнительное действие «Ещё» или «Добавить видео».

# 9. Пожелания клиента

## Материал

**Ключ:** `material_preference`

**Заголовок:**

> Есть пожелания по материалу?

Варианты:

- Не знаю — посоветует мастер
- Кожа
- Перфорированная кожа
- Алькантара / аналог
- Комбинация
- Другое

По умолчанию:

> Не знаю — посоветует мастер

Поле необязательно и tenant может полностью отключить его.

## Строчка

**Ключ:** `stitch_preference`

**Заголовок:**

> Есть пожелания по строчке?

Варианты:

- Как посоветует мастер
- В цвет материала
- Контрастная
- Есть свой вариант

Если выбран «Есть свой вариант» — показать короткое текстовое поле.

Поле необязательно и tenant может отключить его.

## Форма / толщина

**Ключ:** `shape_preference`

**Заголовок:**

> Хотите изменить форму или толщину руля?

Варианты:

- Нет / не знаю
- Сделать толще
- Изменить форму
- Обсудить с мастером

Не превращать это в сложный конфигуратор тюнинга.

- Разрешить уведомления

---

# 19. Что tenant может отключить

Tenant может упростить специализированный шаблон:

- скрыть `material_preference`;
- скрыть `stitch_preference`;
- скрыть `shape_preference`;
- скрыть `vehicle_year`;
- отключить видео;
- изменить тексты/placeholder в разрешённых пределах.

Tenant не может ломать базовый flow, обязательность телефона, сообщения, push/success и утверждённую структуру UI.

---

# 20. Приоритет специализированного шаблона

Если AI уверенно распознал «перетяжку руля», использовать именно этот шаблон.

`automotive.steering-wheel-upholstery` имеет приоритет над `automotive.general`.

Fallback на `automotive.general` используется только если точный адресный шаблон не найден или пользователь сам выбирает общий вариант.
