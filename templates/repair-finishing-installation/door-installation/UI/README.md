# Мобильный UI-референс — «Установка дверей»

Файл `mobile-flow.webp` — **мобильный app-like референс именно этого адресного шаблона**.

## Правило для Codex

1. Сначала соблюдать глобальные утверждённые экраны `/UI`.
2. Затем использовать этот файл как предметный референс для сценария установки дверей: порядок фотосъёмки, названия шагов, характер подсказок и общий визуальный тон.
3. Не превращать изображение в один длинный экран. Это коллаж отдельных мобильных состояний/экранов.
4. Реализовывать интерфейс responsive Vue-компонентами, а не картинкой.
5. Нижняя навигация, camera flow, сообщения, push и служебные состояния остаются общими для LOOKDO.
6. Цвета tenant UI берутся из branding tenant. Тёплая бежево-коричневая гамма этого референса показывает характер именно door-template контента и hint-иллюстраций, а не жёстко заданную тему всего приложения.

### Фото-сценарий

- общий вид помещения;
- дверной проём спереди;
- левая сторона проёма;
- правая сторона проёма;
- верх проёма;
- существующая дверь, если есть;
- дополнительные детали / проблема;
- короткое видео — необязательно;
- референс желаемой двери — необязательно.

Если текст в README/template.json и визуальный коллаж расходятся по бизнес-логике, приоритет имеет актуальный текст шаблона; если расходится визуальная структура — приоритет имеют глобальные `/UI`.
