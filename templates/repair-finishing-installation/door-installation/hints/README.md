# Hint illustrations — «Установка дверей»

Эта папка предназначена для специализированных визуальных подсказок шаблона `repair-finishing-installation.door-installation`.

## Строгое правило

Иллюстрации являются **контентом шаблона**, а не новым UI. Они отображаются внутри существующих карточек/состояний согласно `/UI`.

Не менять ради них структуру экранов.

## Визуальный стиль

- светлый нейтральный фон;
- холодный сине-бирюзовый акцент;
- чистая техническая иллюстрация без брендов;
- минимум лишних предметов;
- дверной проём/дверь изображаются понятно с первого взгляда;
- нужная зона выделяется акцентной рамкой, свечением или полупрозрачной заливкой;
- без текста внутри картинки, чтобы одну иллюстрацию можно было использовать во всех локалях;
- одинаковый ракурс/визуальный язык по всей серии;
- хорошо читается в маленькой mobile-карточке.

## Нужные файлы

- `opening-overall.png` — проём целиком, акцент на всей прямоугольной зоне проёма и части стены вокруг.
- `opening-left.png` — акцент на левой стойке проёма от пола до верхнего угла.
- `opening-right.png` — акцент на правой стойке проёма.
- `opening-top.png` — акцент на верхней перемычке и двух верхних углах.
- `floor-threshold.png` — акцент на нижней части, пороге и уровнях пола по обе стороны.
- `existing-door.png` — существующая дверь в проёме, видны коробка, наличники и петли.
- `problem-detail.png` — пример сложного места: неровность/трещина/повреждение рядом с краем проёма, акцент крупным планом.

Если файл отсутствует, приложение показывает текстовую подсказку без изображения и продолжает работать.
