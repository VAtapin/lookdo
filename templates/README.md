# LOOKDO — библиотека шаблонов заявок

Эта папка — **единственное каноническое место** для описания шаблонов заявок LOOKDO.

Актуальная архитектура шаблонов описана в корневом документе [`TEMPLATE_SYSTEM.md`](../TEMPLATE_SYSTEM.md). Для шаблонов он имеет приоритет над старой моделью `category + variation` из раннего `CODEX.md`.

## Главное правило

У LOOKDO один Request Engine и один Tenant App UI. Профессия/деятельность не получает свой frontend.

Нельзя разносить логику профессий по Vue-компонентам, controller, migration или случайным config-файлам.

Новый шаблон должен добавляться без:

- нового Vue-экрана;
- нового API endpoint;
- новой таблицы БД;
- отдельного controller;
- копии upload/chat/push логики.

Если новый сценарий требует этого — сначала проверить, нельзя ли выразить отличие конфигурацией шаблона.

## Уровни

### 1. Базовое ядро

- `BASE_REQUEST_TEMPLATE.md` — неизменяемый flow всех заявок.
- `base-request-template.json` — машинно-читаемая база.

### 2. Основные шаблоны деятельности

Полностью рабочие fallback-шаблоны:

- `automotive/general.md` — Автомобили и автосервис;
- `repair-finishing-installation/general.md` — Ремонт, отделка и монтаж;
- `appliance-repair/general.md` — Ремонт бытовой техники;
- `furniture/general.md` — Мебель;
- `garden/general.md` — Сад и участок;
- `cleaning/general.md` — Уборка и чистка;
- `bicycles/general.md` — Велосипеды;
- `advertising-signage/general.md` — Рекламные вывески и оформление.

### 3. Адресные специализированные шаблоны

Создаются только там, где действительно нужны свои термины, порядок фотографий, hint images или поля.

Уже есть:

- `automotive/steering-wheel/` — Перетяжка руля;
- `repair-finishing-installation/door-installation/` — Установка дверей.

Адресный шаблон наследует базовую механику и родительский основной шаблон. Он **не копирует приложение целиком**.

## Что меняется в шаблоне

- название;
- CTA;
- заголовок/вводный текст;
- photo/media slots;
- точные инструкции к каждому фото;
- hint images;
- video allowed/recommended;
- несколько универсальных дополнительных полей;
- placeholder/submit/success тексты;
- AI-фразы;
- локализации.

Телефон клиента, отправка, статусы, media storage, сообщения, push, success flow и API-контракт остаются общими.

## Hint images и локальный UI reference

Шаблон может иметь:

```text
hints/
UI/
```

`hints/` — маленькие предметные иллюстрации: какой ракурс/деталь сфотографировать.

`UI/` — только для важных адресных шаблонов: дополнительный мобильный reference конкретного сценария. Он **не заменяет глобальную папку `/UI`**.

Глобальный `/UI` всегда определяет структуру Tenant App. Локальный шаблон определяет содержание.

## Универсальная БД

В runtime шаблоны хранятся в БД и редактируются через Super Admin. Git-файлы — исходник/seed и удобная точка ревью.

Минимально:

```text
request_templates
- id
- code
- category_id
- parent_template_id nullable
- name
- description
- primary_action_label
- title
- intro_text
- photo_min
- photo_max
- video_allowed
- video_recommended
- fields_schema_json
- media_slots_json
- submit_text
- success_text
- enabled
- sort_order
- version
```

Локализуемые тексты — translation records или JSON по локалям, не hardcode в Vue.

Заявочные значения — универсальные `request_fields`, медиа — универсальные `request_media`. Не создавать `car_requests`, `washer_requests`, `door_requests` и т. п.

## AI

AI ищет **request_template**, а не создаёт новый сценарий.

Приоритет:

1. адресный шаблон;
2. основной шаблон деятельности;
3. если ничего не найдено — поддержка.

Текст fallback:

> **Не нашли подходящий шаблон? Напишите в поддержку — мы посмотрим и добавим.**

## Специальные решения, уже зафиксированные

- «Ремонт бытовой техники» — единый основной шаблон для всех обычных видов бытовой техники. Не создавать отдельные шаблоны «стиральная машина», «холодильник» и т. п. без реальной необходимости.
- «Мебель» — отдельная деятельность. Слово «интерьер» сюда не включать: отделка помещения относится к `repair-finishing-installation`.
- «Велосипеды» — отдельная деятельность, не общий раздел «техника и оборудование».
- «Рекламные вывески и оформление» — отдельная деятельность.
